# Ultra Kill Car 🚗💨🧟‍♂️

Динамичный автомобильный зомби-экшен на движке **Godot 4**. Давите толпы зомби, зарабатывайте деньги, улучшайте машины и наслаждайтесь реалистичной физикой столкновений!

## 🌟 Особенности проекта

*   **Реалистичная физика автомобилей:** Уникальные настройки массы, подвески и управляемости для каждого из 4 доступных автомобилей (Mustang, BTR, Pikap, Doge).
*   **Продвинутый Рэгдолл (Ragdoll):** Зомби обладают физически корректным скелетом на базе `ConeTwist` суставов. Никаких «мокрых тряпок» — только честные, мощные удары с кинетической передачей энергии, правильным сопротивлением костей и просчётом столкновений.
*   **Генератор уровней и динамика:** Бесконечные пространства, динамическая камера, реагирующая на скорость автомобиля в стиле NFS, и процедурные 2D визуальные эффекты (искры, дым из-под колес, выхлоп).
*   **Интеграция с Yandex Games SDK:** Проект изначально подготовлен к публикации на платформе Яндекс Игр (сохранения, монетизация).

## 📁 Структура проекта

Проект организован по компонентному принципу, чтобы легко добавлять новые автомобили, врагов и уровни:

```text
ultra-kill-car/
├── addons/
│   └── godot-yandex-games-sdk/  # Плагин для работы с API Яндекс Игр
├── core/                        # Основная логика (Автозагрузка/Синглы)
│   ├── car_vfx.gd               # Процедурная генерация эффектов (дым, искры)
│   ├── game.gd                  # Глобальный контроллер игрового цикла
│   ├── money.gd                 # Система экономики и валюты
│   └── settings.gd              # Настройки и конфигурация игры
├── entities/                    # Все динамические объекты
│   ├── camera/                  # Динамическая следящая камера (CameraFollow)
│   ├── vehicles/                # Транспортные средства
│   │   ├── BTR/                 # Тяжелый бронетранспортер
│   │   ├── Doge_Optimizado/     # Маслкар
│   │   ├── Mustang/             # Спортивный Мустанг
│   │   └── pikap/               # Фермерский пикап
│   └── zombies/                 # Враги
│       └── Z1/                  # Основной тип зомби (с настроенным рэгдоллом)
├── environment/                 # Окружение, модели, препятствия и ландшафт
├── levels/                      # Игровые сцены и меню
│   ├── Generator.tscn           # Логика генерации мира / спавна
│   ├── main.tscn                # Основная игровая сцена
│   └── menu.tscn                # Главное меню игры
└── ui/                          # Интерфейс и магазин (UI/UX)
```

## 🛠 Технические детали

*   **Движок:** Godot Engine 4.x
*   **Рендерер:** Compatibility (GLES3), специально оптимизировано для работы в браузере (WebGL) на слабых устройствах и телефонах.
*   **Настройка физики:** Скелеты зомби переписаны через скрипты (исключены лишние кости, настроены лимиты сгибания `ConeTwist` и добавлена самоколлизия, чтобы избежать провалов сквозь пол).
*   **Эффекты:** Вместо тяжелых 3D партиклов используются легковесные 2D частицы (GradientTexture2D), которые идеально работают в WebGL.

## 🚀 Запуск проекта

1. Убедитесь, что у вас установлен **Godot 4.x**.
2. Откройте файл `project.godot` в редакторе.
3. Главная сцена по умолчанию — `levels/menu.tscn`. Запускайте её (F5) и отправляйтесь крошить зомби!
